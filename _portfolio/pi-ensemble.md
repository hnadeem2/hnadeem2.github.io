Pi-Ensemble is a sequence-guided machine learning framework that combines inverse folding and protein structure prediction to generate intermediate conformations between functional protein states.

The software is modular Python with configurable structure-prediction, inverse-folding, and interpolation backends. It includes reproducible workflows, visualization utilities, testing, and containerized deployment.

**Code:** [github.com/ShuklaGroup/Pi-Ensemble](https://github.com/ShuklaGroup/Pi-Ensemble)

**Preprint:** [Nadeem, Kleiman, et al., bioRxiv (2026)](https://doi.org/10.64898/2026.08.12.744498)
